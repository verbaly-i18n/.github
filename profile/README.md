<h3 align="center">i18n where you write the text in your code</h3>

<p align="center">
  A compiler extracts stable keys, types and one module per language, and a runtime of about 3 KB with zero dependencies renders it.<br />
  React, Vue, Svelte, Next.js, Nuxt, SvelteKit and Astro.
</p>

```ts
t`Welcome back, ${name}`;
```
